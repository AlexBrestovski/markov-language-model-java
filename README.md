Markov Chain Language Model (Java)
## Overview
This project implements a first-order Markov chain language model to estimate the probability that a given text was generated by a specific language or source. The model is trained on text corpora and uses character bigram transition probabilities.


## Key concepts:
- Markov chains
- Bigram language models
- Probability matrices
- Text preprocessing
- Classical NLP

## How it works:
1. Read corpus
2. Count character transitions
3. Convert counts → probabilities
4. Evaluate test strings
5. Select most likely model

## How to Run

This project is a Java command-line application. It requires a Java Development Kit (JDK) to compile and run.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/markov-language-model-java.git
cd markov-language-model-java
```

### 2. Compile the source files

```bash
javac -d out src/hw1/*.java
```

### 3. Run the program

The program expects one or more training corpus files followed by the test string.

```bash
java -cp out hw1.SourceModel <training-file-1> <training-file-2> ... "<test-string>"
```

For example:

```bash
java -cp out hw1.SourceModel english.corpus french.corpus hiphop.corpus "Ou va le monde?"
```

The program first trains a separate Markov model for each corpus. It then calculates the probability of the test string under every model and identifies the model with the highest probability.

### Command-Line Format

```text
java -cp out hw1.SourceModel <corpus-files> "<test-string>"
```

- `<corpus-files>` — One or more text files used to train the source models.
- `<test-string>` — The text whose probability is evaluated by each trained model.

### Notes

The model processes alphabetic characters and ignores non-alphabetic characters when constructing the character-transition model. The transition probabilities are based on consecutive character pairs (bigrams).



## Example Output

For example, given the test string:

```text
"Ou va le monde?"
```

the program produces:

```text
Training english model ... done.
Training french model ... done.
Training hiphop model ... done.
Training lisp model ... done.
Training spanish model ... done.
Analyzing: Ou va le monde?
Probability that test string is  english: 0.02
Probability that test string is   french: 0.85
Probability that test string is  hiphop: 0.01
Probability that test string is     lisp: 0.10
Probability that test string is   spanish: 0.01
Test string is most likely french.
```

The model evaluates the test string using the transition-probability matrix of each trained source model. The source model producing the highest probability is selected as the most likely source of the text.
